# QueryMart_RetailsSalesDatabase
Project about **QueryMart - Retail Sales Database **
QueryMart Retails is a SQL data analysis project focused on solving real-world retail business problems using SQL queries.

All the business questions in this project were solved using SQL in Google Collab. The project covers order analysis, revenue analysis, product performance, customer behavior, warehouse performance, and monthly sales trends.

The goal of this project is to demonstrate how SQL can be used to transform retail data into meaningful business insights.


****Here I have Solved **Business Questions** Solved which are following: **

- Find the total number of orders.
- Calculate total revenue.
- Calculate average order value.
- Find the top 5 most expensive orders.
- Find the second-highest order value.
- Convert product names to uppercase.
- Extract the month from Order Date.
- Classify orders as Small, Medium, or Large using CASE.
- Calculate the average shipping cost, rounded to 2 decimals.
- Find the length of each product name.
- Find monthly revenue.
- Find the top 5 products by revenue.
- Find the top 5 customers by revenue.
- Find the revenue generated by each warehouse.
- Rank warehouses by revenue.
- Calculate the running total of monthly revenue.
- Find the highest-revenue product in each category.
- Find customers whose spending is above average.
- Find products that have never been ordered.
- Identify the best-performing month.
- Find the total number of products.
- Find the number of products in each category.
- Find the 5 most expensive products.
- Find all products with a price greater than ₹10,000.


This project demonstrates practical SQL skills including aggregation, filtering, sorting, string functions, date functions, CASE statements, subqueries, CTEs, window functions, ranking, and analytical queries.
